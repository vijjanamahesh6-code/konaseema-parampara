# Konaseema Parampara Website

A responsive starter website based on the approved homepage design.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — search, category selection, navigation demo interactions
- `assets/` — banner and category images

## Preview locally
1. Extract this ZIP file.
2. Open `index.html` in a modern browser.

For a local development server, run this command from the extracted folder:
```bash
python -m http.server 8000
```
Then visit `http://localhost:8000`.

## Before going live
- Add real product listings, prices, product detail pages and checkout.
- Connect the navigation buttons to your actual pages.
- Add your WhatsApp business number in `script.js` and replace the demo WhatsApp handler with your `https://wa.me/` link.
- Add your business address, policies, delivery details and contact information.
- Set up hosting and a domain, and test the site on mobile.

The search and navigation currently provide front-end demo interactions only. No payment gateway, inventory, customer accounts or backend is connected.
